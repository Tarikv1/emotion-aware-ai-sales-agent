# PRIVATE-CALL-LEARNING-001 - Local-only private call learning scaffold

## Objective

Prepare the project for future private call-center recordings without weakening privacy boundaries or rushing into fine-tuning.

## Scope

This checkpoint defines a local-only learning pipeline for:

- raw audio intake
- local transcription
- speaker segmentation
- redaction
- outcome labeling
- positive and negative sales-pattern mining
- human review
- safe export of minimized learning notes
- deletion or retention manifests

It does not process real private recordings.

## Key Boundary

Raw private audio and raw private transcripts remain under `data/private/`.

The repository may contain:

- policy
- pipeline schema
- command docs
- validation logic
- safe generated scaffold reports

The repository must not contain:

- raw customer audio
- raw private transcripts
- customer identifiers
- exact sensitive personal facts
- provider-upload artifacts from private recordings

## Learning Model

The useful signal is sales behavior, not private facts.

Positive calls can teach:

- what successful human agents say
- when they ask questions
- how they recover objections
- how they handle emotion
- when they close, schedule, transfer, or stop

Bad calls can teach:

- what creates distrust
- what sounds pushy or robotic
- what ignores customer emotion
- what creates compliance or safety risk
- what should become an avoid rule or guardrail

## Output

The scaffold output is generated by:

```powershell
python scripts\check_private_call_learning_pipeline.py
```

The validator is:

```powershell
python scripts\validate_private_call_learning_pipeline.py
```

## Result Interpretation

Passing this checkpoint means the project has a privacy-safe plan and validator for future private call learning.

It does not mean the agent has learned from private call data yet.

Fine-tuning remains a later checkpoint.
