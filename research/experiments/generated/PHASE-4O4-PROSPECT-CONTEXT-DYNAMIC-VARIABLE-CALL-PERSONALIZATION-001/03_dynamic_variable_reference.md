# Dynamic Variable Reference

Use these exact variable names in first-message templates and call setup.

- `{{business_name}}`
- `{{business_type}}`
- `{{vertical}}`
- `{{city}}`
- `{{service_area}}`
- `{{known_website_status}}`
- `{{known_social_presence}}`
- `{{known_booking_or_ordering_path}}`
- `{{suspected_gap}}`
- `{{primary_offer_angle}}`
- `{{likely_decision_maker_role}}`
- `{{contact_name_if_known}}`
- `{{call_reason}}`

## Rules

Use variables to confirm context, not to overstate research.

If the variable value is uncertain, hedge it:

- "I had {{business_name}} down as..."
- "I may be wrong, but..."

Do not invent a value for any missing variable.

Do not claim a website was inspected unless the prospect record explicitly supports that claim.
