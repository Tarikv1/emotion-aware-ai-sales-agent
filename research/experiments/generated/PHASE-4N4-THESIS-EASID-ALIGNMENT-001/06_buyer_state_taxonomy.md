# Buyer State Taxonomy

## Labels

| Buyer state | Definition |
| --- | --- |
| curious | Buyer asks practical questions or invites more detail. |
| skeptical | Buyer challenges credibility, value, or relevance. |
| busy | Buyer has limited attention or asks to shorten the call. |
| annoyed | Buyer signals irritation or resistance to the outreach. |
| price_sensitive | Buyer focuses on cost, budget, or affordability. |
| trust_concerned | Buyer worries about legitimacy, guarantees, or prior bad experiences. |
| high_intent | Buyer shows clear interest in reviewing or taking a next step. |
| low_intent | Buyer gives weak engagement and no concrete buying signal. |
| wrong_person | Buyer is not the decision maker. |
| no_fit | Buyer does not match campaign criteria or has no current need. |
| compliance_sensitive | Buyer requests stop, privacy, consent, or boundary handling. |

## Use In The Agent Evaluation

Buyer state is the bridge between emotion-aware perception and sales behavior. The agent should select strategies based on the buyer state, not force the same pitch across all turns.

## Failure Mode

The first thing likely to break is over-classification: a buyer may be skeptical and price_sensitive at the same time. For the first dataset, use one primary buyer_state_label and record secondary nuance in notes.
