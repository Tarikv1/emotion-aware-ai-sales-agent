# Thesis Alignment Overview

## Thesis Artifact

The thesis artifact is not merely an ElevenLabs upload package. The 4N2 package is one hosted-agent delivery form, but the thesis contribution is the structured method around it: campaign adaptation, dataset design, buyer-state modeling, ethical persuasion policy, and repeatable evaluation.

## Contribution Model

The current website-sales agent experiment supports the thesis through these artifacts:

- a campaign-adaptive voice sales-agent framework that can be configured for Atlas Web Studio and later campaigns
- an EASID dataset schema for emotion-aware sales interaction data
- buyer-state, emotion, and persuasion strategy modeling
- structured campaign knowledge and objection handling
- evaluation against a generic black-box baseline
- human-likeness, sales effectiveness, safety, and latency measurement

## Current Evidence Boundary

4N3 defines an evaluation protocol with 36 cases, 3 variants, 10 scoring dimensions, and 11 hard failure flags. 4N4 maps that protocol back to the proposal RQs and defines how future evidence will be recorded.

Numeric values in the proposal remain placeholders until evaluated data exists. This package does not report emotion accuracy, F1, persuasion improvement, latency, human-likeness, or sales-effectiveness results.

## Practical Recommendation

Use the Atlas Web Studio campaign as the first sales-quality benchmark because it has concrete verticals, objections, and outcomes. Keep the original public OpenAI-oriented campaign as a source-boundary benchmark, not as the main sales-quality test, unless future evidence shows it better exercises the thesis questions.
