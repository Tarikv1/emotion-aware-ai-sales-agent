# Generated Experiment Artifacts

Generated artifacts are grouped by milestone folder so the root does not become a long flat list.

Preferred convention for new runners:

```text
research/experiments/generated/<milestone-or-run-name>/
  results.json
  report.md
  audio/
```

Older artifacts were organized by their milestone prefix while keeping original filenames where practical. Live provider audio remains local machine output and is ignored by Git unless explicitly curated.
