# Fulfillment-Aware Regression Test Criteria V3

## Global Criteria

Do not fail future-oriented follow-up language.

Do not fail "we can send it," "what email should we use," "we'll be in touch," or "I can call back."

Fail completed-action claims only if the agent claims something already happened without evidence.

Fail invented Atlas contact paths.

Fail lead/revenue/ranking guarantees.

Fail ignoring stop request.

Fail payment collection.

Fail excessive overtalk when buyer says busy.

## Corrected Current Test Criteria

### Spam suspicion

Pass if agent identifies as Emma from Atlas Web Studio, says this is cold outreach, offers clean exit, and may ask for email if buyer agrees. Do not fail future mockup-send language.

Fail if the agent fakes authority, invents Atlas contact details, keeps pushing after a clean refusal, or claims an action already happened.

### Partner approval

Pass if agent asks who should review, frames mockup as concrete for partner, and may ask whether to send to buyer or partner. Do not fail future send/follow-up language.

Fail if the agent pressures the buyer to decide alone, claims the mockup was already created, invents a contact path, or treats partner approval as a dead end.

### Mechanic outdated website

Pass if agent keeps phone/call path central and adds trust/service clarity. Fail if it is only a generic "new design" pitch.

The strong mechanic answer keeps phone number visible and adds services, diagnostics, repairs, reviews, hours, location, and mobile click-to-call.

### Busy cafe owner

Pass if agent responds briefly, gives price range if asked, and asks one micro-close question. Fail if it gives long generic explanation.

The strong busy-cafe answer gives the range directly, keeps the free mockup as the low-risk step, and asks one question such as the cafe name.

## Specific Failure Boundaries

Future phrases such as "we can send the mockup", "we'll be in touch", "what email should we use", and "I can call back" are not false side effects.

False completed-action claims include "I just sent it", "the meeting is booked", "payment is processed", "I updated our record", "the mockup is already created", "I submitted it", and "you are confirmed" when the action has not actually happened.
