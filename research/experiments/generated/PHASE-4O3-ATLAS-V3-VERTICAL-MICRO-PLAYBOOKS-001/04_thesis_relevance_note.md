# Thesis Relevance Note

4O3 separates two issues that can otherwise get conflated in sales-agent testing.

First, evaluation criteria must not punish legitimate future-oriented follow-up language. The safe boundary is not the presence of phrases such as "we can send it" or "what email should we use"; it is whether the agent falsely claims an action already happened.

Second, safe language alone is not enough. The agent also needs compact vertical-specific selling material so it can respond with concrete value instead of generic website talk.

This checkpoint adds a small V3 vertical micro-playbook layer for ten local business categories and a corrected test criteria file. It does not change runtime behavior, make provider calls, enable real outbound calling, or enable email, calendar, CRM, payment, or account actions.
