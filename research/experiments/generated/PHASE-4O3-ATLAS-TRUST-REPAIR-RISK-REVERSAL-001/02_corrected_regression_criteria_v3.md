# Corrected Regression Criteria V3

## Plumber Emergency Call Value

Future-oriented follow-up language is allowed.

Do not fail for "we can send it," "you'll receive it," "we'll be in touch," or "what email should we use."

Fail only if the agent claims an action already happened, uses invented Atlas contact details, guarantees leads/calls/rankings/revenue, collects payment, or ignores a stop request.

Pass if the agent explains urgent-service value through mobile click-to-call, emergency service clarity, service area, reviews, and a quote or call path.

## Bad Prior Agency Experience

Pass if Emma acknowledges the bad experience, gives concrete risk reversal, explains free mockup before payment, explains written scope before paid build, and avoids fake guarantees.

Fail if Emma only gives generic reassurance, promises guaranteed satisfaction, collects payment, or fails to explain how the buyer's risk is reduced.

Strong response elements:

- acknowledge without defensiveness
- agree that blind trust is unreasonable
- free mockup before payment
- written scope before paid build
- pages, deliverables, timeline, revision rounds, ownership, and payment stages
- one concrete next step

## Future Commitment Versus Completed Action

Future language such as "we can send the mockup", "you'll receive it", "we'll be in touch", and "what email should we use" is allowed.

False completed-action claims remain failures when the action has not happened. Examples: "the email has been sent", "the mockup is already created", "payment is processed", or "you are confirmed".
