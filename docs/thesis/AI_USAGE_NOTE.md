# AI Usage Note

## Purpose

Document the supervisor-approved use of AI tools in the technical development of this thesis project.

## Position

The thesis supervisor has explicitly allowed the use of AI for the technical part of the thesis project.

In this project, AI may be used for:

- technical planning
- implementation support
- experiment structuring
- prompt design
- dataset inspection assistance
- engineering iteration
- code review and debugging support
- validator and evidence-packet design
- source-bundle and documentation planning
- documentation support for technical workflow
- evidence interpretation and thesis-document update support
- local-model experiment planning and result interpretation
- audio/prosody architecture planning under explicit no-provider/no-runtime boundaries

## Boundary

The final thesis authorship remains the student's responsibility.

This means:

- the student is responsible for the final written thesis
- the student is responsible for understanding, validating, and defending the technical work
- AI assistance does not replace academic responsibility for claims, methodology, or conclusions
- AI-generated plans or code changes are not sales-quality proof
- human review remains necessary for live-call quality, voice naturalness, product claims, ethics, and compliance
- manual listening review can override technically successful audio generation when intelligibility or quality fails
- local model experiments and generated evidence do not replace independent evaluation of latency, quality, or product readiness

## Practical Interpretation For This Project

AI assistance is permitted as part of the engineering and research workflow for building, testing, organizing, and documenting the technical components of the thesis.

The final thesis text, framing, argumentation, and submission remain authored and owned by the student.

Codex and ChatGPT have been used to help create phase prompts, implement local code and documentation changes, design validators, summarize generated evidence, interpret local experiment results, and keep public/private/source boundaries visible. The user made project decisions and manual qualitative judgments, including the Liquid TTS retirement after manual listening review. The project should not state that AI autonomously verified sales effectiveness, live readiness, voice quality, or production readiness.
