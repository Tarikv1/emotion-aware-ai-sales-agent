# Thesis Writing Guide

Use this folder as the running memory of the thesis, not just as a place for polished final text.

## Purpose

Capture decisions, rationale, dataset choices, experiment scope, and evaluation notes while the project is being built so the eventual thesis draft can be written from project artifacts instead of reconstruction from memory.

## What To Record As We Work

- why a dataset was chosen or rejected
- why a metric was chosen or postponed
- why a model, rule set, or architecture was selected
- what changed in scope and why
- what failed and what was learned
- what limitations were discovered

## Thesis-Friendly Document Map

- `PROJECT_BRIEF.md`: stable project definition
- `FIRST_EXPERIMENT_PLAN.md`: first experimental slice
- `METHODOLOGY_LOG.md`: running record of what was done and why
- `DECISION_LOG.md`: important decisions with rationale
- `THESIS_OUTLINE.md`: draft chapter skeleton and likely evidence sources

## Writing Rule Of Thumb

If a future thesis sentence would begin with:

- `We decided to...`
- `The system was designed to...`
- `The dataset was selected because...`
- `A limitation of this approach is...`

then that thought probably belongs in one of the thesis docs now.
