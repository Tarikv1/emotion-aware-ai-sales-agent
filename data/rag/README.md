# RAG Data Workspace

This folder is reserved for local, source-tracked RAG assets for the Emotion Aware AI Sales Agent.

RAG-001 and RAG-002 do not place permanent runtime memory here yet. They write generated previews and NotebookLM prompt packs under:

```text
research/experiments/generated/RAG-001-notebooklm-source-intake-bridge/
research/experiments/generated/RAG-002-notebooklm-extraction-automation-bridge/
```

Future promoted RAG assets can live here after source, copyright, privacy, and thesis-reference checks pass.

Do not store:

- API keys
- raw private customer data
- raw private call-center audio or transcripts
- copied book chapters
- pasted full articles
- full video transcripts
- unsourced NotebookLM notes
