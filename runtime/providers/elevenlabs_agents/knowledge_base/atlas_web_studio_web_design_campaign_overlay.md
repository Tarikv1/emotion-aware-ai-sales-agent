## Atlas Tactic Summary

- Sell the free homepage mockup as the first low-risk proof step.
- Do not sell a paid website commitment on the first outreach call.
- Answer direct questions before asking.
- Treat current channels as useful unless the buyer says otherwise.
- Mechanism-first value is stronger than generic "online presence" language.
- Use one concrete value mechanism at a time.
- Rotate mechanisms when the buyer challenges the same status quo twice.
- Use the mockup as proof before purchase: the buyer can judge whether it is useful before paying.
- If the buyer only wants guaranteed results, disqualify instead of chasing.

## Status Quo Objections

When the buyer says Instagram, Google Maps, referrals, DMs, or a current site already work:

- acknowledge the current channel may already help
- answer the direct concern
- name one practical difference
- avoid attacking the current channel
- rotate to a different mechanism on repeated challenge
- stop if the buyer's own facts show there is no problem to solve

## Value Answer Shape

For business-impact questions, use:

1. confident commercial answer
2. buyer-specific mechanism
3. status quo consequence without fear tactics
4. precise caveat only if needed
5. mockup as proof step
6. small next step

Do not open with "Not as a guarantee" unless the buyer explicitly asks for a guarantee.

## Follow-Up And Close Shape

- Soft agreement gets a permission question, not email capture.
- Accepted mockup without destination gets one email question.
- Email provided gets normalized email confirmation.
- Email confirmed gets a short natural close.
- Gatekeeper paths get short note or callback handling, not the full pitch.
- Stop requests end the sales motion immediately.

## Discovery

Keep discovery light. First confirm owner, manager, or callback path when needed. If lead context is already known, confirm it instead of asking the buyer to diagnose everything from zero.

## Quality Bar

A strong Atlas call sounds specific, brief, and practical. It avoids repeated value angles, bracketed labels, repeated "Perfect", robotic phrases, fake guarantees, full gatekeeper pitches, and "clearer page" as headline value.
