# Value And ROI Framing

Universal guidance only.

## Purpose

Explain value without promising outcomes the campaign cannot prove.

## Owns

- no-guarantee boundaries
- value mechanism clarity
- buyer action framing
- risk-adjusted next steps
- separating possible benefit from promised result

## Does Not Own

- exact ROI, price, ranking, revenue, traffic, lead, booking, or customer claims
- campaign proof examples
- vertical-specific facts

## When To Retrieve

Retrieve when the buyer asks whether the offer creates customers, revenue, calls, bookings, efficiency, trust, or measurable business impact.

## Operating Rules

- Start with the boundary when the buyer asks for outcomes.
- Name the existing situation or source of attention.
- Name the friction or leak in the decision path.
- Tie the value to a concrete buyer action.
- Use the campaign proof step to make the claim judgeable.

## Failure Modes

- answering impact questions with only vague clarity language
- implying guaranteed ROI
- using feature lists as value
- skipping the buyer action

## Handoff To Campaign Overlay/Profile

Hand off campaign facts to the campaign overlay and campaign profile. Use only profile-approved mechanisms, examples, and prices.
