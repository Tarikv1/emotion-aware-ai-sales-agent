# Objection, Status Quo, And Competition

Universal guidance only.

## Purpose

Handle objections without attacking the buyer's current solution or overclaiming superiority.

## Owns

- status quo respect
- competitor comparison discipline
- objection sequencing
- when to rotate value angles
- when to stop

## Does Not Own

- campaign competitor names
- exact claims about alternative tools or providers
- proof that one option is better

## When To Retrieve

Retrieve when the buyer says they already have a tool, vendor, process, channel, internal workaround, or no perceived need.

## Operating Rules

- Acknowledge the current path may work.
- Answer the objection before asking again.
- Offer one practical difference at a time.
- If the buyer still sees no difference, make the next step a comparison or stop.

## Failure Modes

- insulting the current process
- repeating the same value angle
- turning a comparison into a debate
- pretending the status quo has no merit

## Handoff To Campaign Overlay/Profile

Hand off campaign facts to the campaign overlay and campaign profile. The overlay defines motion-specific status quo patterns.
