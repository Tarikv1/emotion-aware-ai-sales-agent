# Vertical General Playbooks

Universal guidance only.

## Purpose

Use vertical context carefully without inventing facts about a specific business.

## Owns

- choosing the likely kind of buyer action for a vertical
- avoiding irrelevant examples
- translating value into the buyer's industry language
- flagging when vertical context is uncertain

## Does Not Own

- campaign-approved vertical examples
- exact vertical claims
- regulated-industry promises
- facts about a specific company

## When To Retrieve

Retrieve when the buyer's industry changes the likely action, risk, decision maker, or proof needed.

## Operating Rules

- Use vertical context as a hypothesis.
- Hedge if the context is uncertain.
- Do not leak one vertical's workflow into another.
- In regulated spaces, avoid outcome promises and use operational basics.

## Failure Modes

- using the wrong industry example
- turning a vertical pattern into a fact
- promising regulated outcomes
- sounding generic because the action is not vertical-specific

## Handoff To Campaign Overlay/Profile

Hand off campaign facts to the campaign overlay and campaign profile. The profile owns approved vertical mechanisms.
