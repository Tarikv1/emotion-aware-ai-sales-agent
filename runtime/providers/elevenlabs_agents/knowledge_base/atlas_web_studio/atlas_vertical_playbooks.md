# Atlas Vertical Playbooks

Each vertical includes main buyer pain, strongest website mechanism, current-channel objection, concise example answer, and disqualification signal.

## salon/barber

- main buyer pain: photos get attention, but services, pricing, policies, and booking rules live in DMs.
- strongest website mechanism: booking filter plus DM reduction.
- current-channel objection: Instagram already works.
- concise example answer: "Instagram may already bring attention. The site helps people check services, prices, policies, reviews, and booking rules before they DM."
- disqualification signal: Instagram already fills the calendar and the buyer does not want more bookings.

## plumber/electrician/HVAC

- main buyer pain: urgent buyers compare fast and need service area, trust, and tap-to-call.
- strongest website mechanism: trust-before-call page plus service-area page.
- current-channel objection: Google Maps already works.
- concise example answer: "Maps may get the click. The site helps someone quickly check service area, job type, reviews, and tap-to-call before choosing who to contact."
- disqualification signal: buyer only wants guaranteed emergency calls or pay-per-lead.

## mechanic/auto repair

- main buyer pain: people hesitate before trusting a shop with diagnostics or repairs.
- strongest website mechanism: comparison page plus tap-to-call page.
- current-channel objection: reviews and Maps already exist.
- concise example answer: "Reviews help. A site can show diagnostics, repairs, hours, location, and the phone path before someone decides which shop to call."
- disqualification signal: current site already produces the right calls and the owner is satisfied.

## restaurant/cafe

- main buyer pain: customers need menu, hours, photos, location, and reservation/order path quickly.
- strongest website mechanism: after-hours answer page plus tap-to-call or order/reservation path.
- current-channel objection: Google Maps and Instagram already show basics.
- concise example answer: "Maps can help people find you. The site helps them choose by checking menu, hours, photos, location, reviews, and how to reserve, order, or call."
- disqualification signal: buyer does not want any more orders, calls, visits, or reservations.

## dental/clinic

- main buyer pain: new callers need office basics without medical growth claims.
- strongest website mechanism: trust-before-call page plus local search foundation.
- current-channel objection: Google listing already has phone and reviews.
- concise example answer: "The goal is not a patient-growth promise. A site can show services, location, hours, reviews, and appointment contact options so someone can decide whether to call."
- disqualification signal: buyer demands patient-growth certainty or treatment-result claims.

## cleaning

- main buyer pain: owners lose time on bad-fit quote requests.
- strongest website mechanism: quote filter.
- current-channel objection: referrals already work.
- concise example answer: "Referrals can keep working. The site can filter quote requests by service area, one-time versus recurring, move-in or move-out, included scope, and how to request a quote."
- disqualification signal: referrals fill capacity and the owner does not want more quote volume.

## real estate

- main buyer pain: sellers and buyers compare agents before asking for a valuation or consultation.
- strongest website mechanism: comparison page plus trust-before-call page.
- current-channel objection: broker profile or social already exists.
- concise example answer: "The broker page can still help. A focused page can make local expertise, listings, reviews, and valuation or consultation path easier to judge."
- disqualification signal: brokerage rules prohibit independent pages or the agent only wants guaranteed listings.

## law office

- main buyer pain: prospects need practice area, credibility, location, and consultation path without outcome promises.
- strongest website mechanism: trust-before-call page plus FAQ / price / policy filter where appropriate.
- current-channel objection: referrals already drive cases.
- concise example answer: "Referrals can stay the main source. The site helps referred people check practice area, location, credibility, and how to request a consultation before calling."
- disqualification signal: buyer wants legal outcome guarantees or unsupported claim language.

## gym/trainer

- main buyer pain: people see content but do not know program fit, schedule, proof, or trial/session path.
- strongest website mechanism: pre-qualification plus booking filter.
- current-channel objection: Instagram already shows workouts and transformations.
- concise example answer: "Instagram may create interest. The site helps someone check programs, schedule, fit, proof, and how to start without digging through posts."
- disqualification signal: DMs already produce enough qualified clients and the owner does not want more inquiries.
